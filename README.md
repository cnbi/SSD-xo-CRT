# Sample Size Determination for Cluster Randomised Crossover Trials with Bayesian Hypothesis Testing

**Author**: Camila Barragan

# Overview

This repository is the research compendium for the manuscript "Method of Sample Size Determination for Cluster Randomised Crossover Trials with the Bayes Factor". The repository contains all the files used in the simulation study as well as the files used in the motivation example.
